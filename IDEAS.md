# Ideas

The single backlog. One row per idea. When an idea is picked, run `scripts/new-video.sh "<working title>" <format>` and put the folder id in the Folder column.

Status: `idea` > `researching` > `scripting` > `building` > `ready` > `published` (or `parked` / `dropped`).
Score = Curiosity + Emotion + Share + Fresh angle + Feasibility, each 0 to 2 (see `.claude/skills/video-studio/references/virality.md`). Build 8 and above first.
Format: documentary, essay, short-doc, short, listicle, news, cartoon, commentary, story (see `references/formats.md`).
